# 工具与宿主

## 统一执行契约

工具由后端 Agent 循环选择并执行。每次调用包含稳定工具调用 ID、参数、所属会话与运行，返回结果、失败或取消状态。审批、工作目录、可访问根目录和 sandbox 策略贯穿执行过程。

当前实现入口包括 `internal/tools/`、`internal/agent/tool_execution.go`、`internal/backend/terminal_http.go` 和 `LiveAgent/crates/agent-gui/src-tauri/src/services/`。工具注册、schema、权限、UI 和宿主行为需要一起核对。

## 进程与终端

ManagedProcess、ProcessWait、ProcessStop、ReadTerminal 和 PTY 终端应共同满足：

- 进程归属可追踪，取消联动到子进程组。
- 输出使用有界缓冲或分页日志，并返回游标和截断信息。
- CWD 与访问根目录经过同一权限检查。
- 前端请求传递真实的 conversation/run/session 身份。
- 服务退出等待进程和持久化完成。

当前 canonical 终端依赖已接收的运行身份。全局状态页、空闲终端、运行完成后的读取保留及跨重启恢复仍需补齐。聊天列表/创建请求的身份接入只覆盖该请求路径。

## SSH、SFTP 和 Tunnel

这些能力属于 LiveAgent 既有功能。迁移需要保留配置、认证提示、标签页、重连、文件传输、本地转发和端口状态。后端与原生宿主桥必须明确执行宿主、凭据持有方、审批上下文和响应归属。

验收分别覆盖本地宿主、远程宿主、Gateway WebUI；通过一个原生单测无法证明 canonical 远程链路已完整接管。

## 浏览器与计算机控制

浏览器生命周期区分用户已有浏览器、显式专用 profile 和自动创建的备用实例。仅对自己拥有的实例执行进程回收。页面/标签识别、截图、输入、下载与文件权限都需要真实浏览器验证。

浏览器和计算机工具的运行身份及权限须与 Agent 会话关联；本地开发 CDP 验收是测试机制，产品的浏览器工具是另一条能力链。

## 验收重点

真实执行 → 输出读取 → 中途取消 → 后续请求 → 服务关闭；错误身份拒绝；权限拒绝；只读根目录；输出截断；断线重连；已有用户浏览器保持存活。Windows、Unix PTY 和各原生平台的差异单独标注。
