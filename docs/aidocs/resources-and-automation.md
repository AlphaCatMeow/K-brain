# 资源与自动化

## 资源归属

Skills、MCP、记忆、提示词、Hooks 和 Cron 由 K-brain 管理执行与持久化。LiveAgent 保留资源入口、设置、编辑和状态显示。资源更新成功后通知或刷新消费者，失败时保留可重试状态。

| 资源 | 后端位置 | 主要要求 |
| --- | --- | --- |
| Skills | `internal/skills/` | 扫描、发现、安装、更新与启停 |
| MCP | `internal/mcp/` | schema 发现、动态重载、工具调用和连接清理 |
| 记忆 | `internal/memory/`、`internal/memoryruntime/` | 提取、注入、整理、历史与调度 |
| 提示词 | `internal/prompts/`、`internal/resources/` | 系统/项目资源加载与会话应用 |
| Hooks | `internal/hooks/`、后端 hook 接口 | 生命周期、执行上下文和失败呈现 |
| Cron | `internal/scheduler/`、后端 cron 接口 | 调度、运行、取消和历史 |

## MCP

使用已发现的 schema 构造调用。导入配置保留来源文件，并校验服务器配置、工具启用状态与实际连接结果。重载时防止失效连接继续接收新调用；活动调用的取消、超时和错误归属保持一致。

## 记忆

后台提取与前台聊天请求分别计数、跟踪和取消。模型切换、会话删除与关闭服务应清理所属 memory runtime。记忆整理需要区分当前去重实现与目标模型驱动规划，后者的调度和完整界面仍待验收。

## Cron

计划提示执行与 HTTP 提交共用后端 canonical run 启动路径。任务保存后端会话关联，运行日志保存 session/run ID。工作空间变化与模型变化分别遵循会话和模型切换规则。

无人值守运行应明确处理交互审批和提问。取消与超时保留各自原因；任务模态框切换、清空日志后返回旧请求、刷新活动运行等场景需要防止过期响应覆盖界面。

## 迁移和验收

资源操作覆盖创建/导入、保存、重载、执行、取消、删除和重启。桌面原生数据导入与 Gateway 转发分别验收；受控 MCP 或模型上游结果应注明环境。资源入口保留，尚未实现的执行链路列入功能对齐计划。
